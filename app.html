Paramètres
Comment ajouter un nouveau locataire ?expand_more
Ouvrez Locations depuis le menu latéral, puis cliquez sur Nouvelle location. Dans le formulaire, cochez Nouveau locataire pour créer sa fiche en même temps que la location.
Comment enregistrer un paiement ?expand_more
Depuis la page Paiements, cliquez sur + Nouveau paiement. Sélectionnez le contrat, saisissez le montant et la date, puis enregistrez.
Comment générer un rapport PDF ?expand_more
Accédez à la page Rapports, sélectionnez la période souhaitée, puis cliquez sur le bouton Exporter PDF en haut à droite.
Comment créer un contrat de location ?expand_more
Ouvrez Locations depuis le menu latéral, puis cliquez sur une location. Le contrat, les dates, le loyer, la caution et les échéances se gèrent directement dans la même fiche.
Comment activer le mode sombre ?expand_more
Cliquez sur l'icône lune dans la barre en haut à droite pour basculer entre le mode clair et le mode sombre.
Comment gérer les droits d'accès des employés ?expand_more
Dans Employés, ouvrez la fiche d'un employé et cochez les modules auxquels il doit avoir accès. Les restrictions s'appliquent immédiatement à la prochaine connexion.
Les données sont-elles sauvegardées automatiquement ?expand_more
Oui, toutes les modifications sont sauvegardées automatiquement en local (localStorage). Si Supabase est configuré dans les Paramètres, les données sont aussi synchronisées en cloud.
