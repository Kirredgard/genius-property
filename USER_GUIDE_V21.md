# Guide utilisateur V21

## 1. Connexion

Ouvrir `login.v21.html`, se connecter avec le compte fourni.

## 2. Agence

Si aucune agence n’existe, ouvrir `onboarding.v21.html`.

## 3. Données de base

Ajouter dans cet ordre :

1. Propriétaires
2. Biens
3. Locataires
4. Contrats
5. Documents

## 4. Feedback beta

Utiliser `feedback.v21.html` pour signaler :

- bug
- idée
- question
- remarque positive

## 5. Support

Ouvrir `support.v21.html`.

## 6. Diagnostic

En cas de problème :

- `health.v21.html`
- `observability.v21.html`
- capture console navigateur
