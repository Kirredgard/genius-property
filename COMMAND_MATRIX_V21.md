# Command Matrix V21

```bash
npm install
npm run dev
```

## Qualité

```bash
npm run healthcheck:v21
npm run audit:imports
npm run typecheck
npm run test
npm run audit:legacy
npm run audit:legacy:strict
```

```bash

npm run production:check

npm run production:ready
```
