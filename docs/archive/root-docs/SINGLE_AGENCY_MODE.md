# Genius Property — mode agence unique

Cette version est préparée pour **une seule agence** et un **usage interne**.

## Ce qui a été retiré de l'interface
- abonnement
- activation de licence
- gestion des licences
- administration SaaS / espace clients
- éléments de présentation commerciale/SaaS sur la connexion

## Ce qui reste
- biens
- propriétaires
- locataires
- locations
- contrats
- paiements
- dépenses
- employés et droits d'accès
- agenda
- messages
- journal
- paramètres
- stockage & synchronisation

Le fonctionnement métier et l'authentification des employés restent en place. Le mode n'impose pas de système de licence ou de paiement.

Pour personnaliser le nom de l'agence, modifiez les textes de marque dans `index.html`.
