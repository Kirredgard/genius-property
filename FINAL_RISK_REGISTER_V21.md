# Final Risk Register V21

## Risques restants avant beta

1. Firebase Rules à tester avec vrais rôles
2. Stripe webhooks à tester en mode test réel
3. Email API à brancher à un SMTP réel
4. Suppression legacy à faire progressivement
5. Performance à mesurer après build production
6. Données beta à sauvegarder avant tests clients
7. Monitoring externe à connecter si production publique

## Décision

Le projet est prêt pour une beta contrôlée, pas encore pour une ouverture publique massive sans staging réel.
